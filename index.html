The shift

Your readers aren’t all human anymore.

ChatGPT, Claude, Perplexity and a growing fleet of agents now visit sites to answer questions, buy things, and act on behalf of people. They don’t read your theme — they read your signals: robots rules, sitemaps, machine-readable content, and capability descriptors. Most WordPress sites emit almost none of them, and there’s no dashboard telling you so. AIScanner is that dashboard.

How it works

Scan. Fix. Verify — then keep it fixed.

A closed loop, not a one-off report. Every check fetches your site the way a crawler would, so a passing score reflects what an agent actually sees — even when a CDN or a stray robots.txt is overriding WordPress.

STEP 01

Scan over real HTTP

Grades five dimensions against a versioned rubric by fetching live URLs — never trusting internal plugin state. What a crawler sees is what gets scored.

STEP 02

Apply one-click fixes

Every fix writes plugin settings and nothing else. No theme edits, no rewritten posts — so “Turn off” genuinely restores the prior state. Fixes are fully reversible.

STEP 03

Re-scan to prove it

Verify re-fetches over a live request to confirm the score actually moved. A scheduled re-scan catches drift, so what you fixed stays fixed.

What it grades

Five dimensions. Fifteen checks. One weighted score.

Each check earns points toward its dimension; dimensions roll up to an overall 0–100 score and a readiness level. Inapplicable dimensions are excluded from the denominator, so the number always reflects your site.

Why AIScanner

A scanner you can trust to fix things.

Plenty of tools flag what’s missing. AIScanner fixes it safely, proves the fix, and stays out of your content’s way.

Reversible by design

Every fix writes plugin settings only — no theme edits, no rewritten posts. Turning a fix off restores the exact prior state.

Real HTTP verification

Checks fetch your live site, catching a CDN or physical robots.txt that overrides WordPress — the kind of thing internal state hides.

Privacy-first

Requests hit your own site only. Nothing is sent to any third party, and there is no telemetry — not now, not opt-out-later.

Drift protection

A scheduled re-scan re-checks your score on a cadence, so a theme update or host change that regresses a signal doesn’t go unnoticed.

Plays well with SEO plugins

Detects Yoast, Rank Math and AIOSEO and defers per feature — so you never end up with two sitemaps or two JSON-LD graphs.

Agent-callable MCP server

An optional MCP server exposes scan / fix / verify / revert as tools an agent can call directly. Off by default, gated by a token you generate.

For agents, by design

Let an agent run the whole loop.

Flip on the optional MCP server and your readiness workflow becomes a set of tools an AI agent can invoke itself — scan, apply a fix, verify over HTTP, revert if needed.

  • Off by default. Nothing is exposed until you explicitly enable it in Settings.
  • Bearer-token gated. Stored as a SHA-256 hash, shown once, never included in an export.
  • Hardened. Origin-validated and rate-limited against failed authentication per IP.
